# Release Notes: v2026.06.15-workbench-file-context

Datum: 2026-06-15

## Zweck

Dieser Handover-Stand stellt die Workbench auf verbindlichen Datei-Kontext pro Modell um. Jedes Chat-Modell nutzt einen kurzen deterministischen Systemprompt, verweist auf `mainprompt.md`, `fachwissen.md` und `Golden_Example.<ext>` und lädt diese drei Pflichtdateien beim OpenWebUI-Import als echte Files hoch. Weitere Dateien aus `beispiele/` bleiben Knowledge/RAG-on-demand.

## Neue und aktualisierte Inhalte

- Pflichtdatei-Kontext für alle Workbench-Modelle ergänzt.
- `Golden_Example.<ext>` pro Modell erzeugt und in die Importartefakte aufgenommen.
- `workbench_required_file_context_filter` ergänzt und `context_compressor_filter` so gehärtet, dass Pflichtkontext geschützt bleibt.
- OpenWebUI-Importer und Generator auf echte File-Uploads für Pflichtdateien und Knowledge-only-Behandlung für Beispiele angepasst.
- Workbench-GUI um auswählbares Basismodell, Bulk-Aktionen und detaillierte Live-Logs für lange Aktionen erweitert.
- Standard-Chatmodell bleibt konfigurierbar; der lokale Default ist `coder`, nicht hart im Code auf einen Provider-Pfad festgelegt.
- Öffentliche Infrastrukturmarker-Prüfung ergänzt und lokale torvs-spezifische Übergabevorlagen entfernt.
- Historische Root-Snapshot-Notizen entfernt; aktuelle Dokumentation verweist auf Verify-Runner und Maintainer-Checkliste.
- Dist-Artefakte und ZIP-Handover neu erzeugt.
- Offline-Docker-Image `openwebui-workbench-dashboard:seu` neu gebaut und als lokaler Portainer-Import-Tar exportiert.
