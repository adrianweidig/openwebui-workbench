# Release Notes: v2026.06.15-workbench-file-context

Date: 2026-06-15

## Purpose

This handover release moves the Workbench to mandatory file context per model. Every chat model uses a short deterministic system prompt, references `mainprompt.md`, `fachwissen.md`, and `Golden_Example.<ext>`, and uploads those three required files as real OpenWebUI files during import. Additional files under `beispiele/` remain Knowledge/RAG-on-demand material.

## What changed

- Added required file context for all Workbench models.
- Generated one `Golden_Example.<ext>` file per model and included it in the import artifacts.
- Added `workbench_required_file_context_filter` and hardened `context_compressor_filter` so required context remains protected.
- Updated the OpenWebUI importer and generator for real required-file uploads while keeping examples as Knowledge-only material.
- Extended the Workbench UI with selectable base models, bulk actions, and detailed live logs for long-running actions.
- Kept the default chat model configurable; the local default is `coder` and not hardcoded to a provider path.
- Added public infrastructure marker checks and removed local domain-specific handover templates.
- Removed historical root snapshot notes; current documentation points to the verify runner and maintainer checklist.
- Regenerated dist artifacts and ZIP handover packages.
- Rebuilt the offline Docker image and validated the local container handover path.
