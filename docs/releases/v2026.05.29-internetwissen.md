# Release Notes: v2026.05.29-internetwissen

Date: 2026-05-29

## Purpose

This handover release integrates and hardens the `internetwissen` model as an offline research and explanation model. The offline default remains free of live web search, public HTTP fetchers, GitHub inspectors, and crawling tools.

## What changed

- Expanded `internetwissen` domain knowledge, main prompt, system prompt, and golden example.
- Added examples for time-sensitive version questions, local sources, KnowledgePack usage, source avoidance, internet basics, and research matrices.
- Added an offline data policy with KnowledgePack structure and a 10 GiB total budget.
- Added KnowledgePack validation and offline data-budget checks to the verify runner.
- Reduced the `internetwissen` tool profile to an offline-minimal set.
- Updated README, English README, roadmap, changelog, model inventory, and release process documentation.
- Added localized Workbench screenshots for `internetwissen`.
- Regenerated OpenWebUI dist artifacts and ZIP handover packages.

## Known limits

- Production OpenWebUI API imports are not part of this release-note artifact.
- Large web corpora, Wikipedia/Kiwix dumps, FineWeb/Common Crawl data, or external vector indexes are not included.
- OpenWebUI screenshots are not versioned when they would expose local user accounts, tokens, or private instance data.
- GHCR image tags count as updated only after the GitHub Actions Docker run for the final commit has completed successfully.

## Container images

Air-gap image exports are documented in `Deployment/images/README.md`. Large image tars should be published only through Git LFS or release assets after budget, hash, and maintainer approval are clear.
