# Internationalization

🌐 Languages: [Deutsch](../de/I18N.md) | [English](I18N.md)

## Language Standard

German is the default language for the README, dashboard UI, default documentation, CLI-adjacent status messages, and human-readable fallbacks. English is the main alternative language. Additional languages should be possible without breaking the German default route.

## Locale Detection

The Workbench dashboard uses this priority:

1. manual browser selection, stored as `workbench-locale`
2. `WORKBENCH_LOCALE` in the dashboard process
3. browser and HTTP language such as `navigator.language` or `Accept-Language`
4. system variables such as `LC_ALL`, `LC_MESSAGES`, or `LANG`
5. stable fallback to German

Unknown or unsupported values such as `fr-FR` fall back to German.

## Resources

- Dashboard UI: `Workbench/dashboard/static/locales/de.json` and `Workbench/dashboard/static/locales/en.json`
- Dashboard/API messages: `Workbench/dashboard/i18n.py`
- Product locales for model packages: `Modelle/einzelmodelle/<model-id>/i18n/*.md`
- Central product locale manifest: `Modelle/i18n/product-locales.json`
- Product i18n generator: `scripts/generate_model_i18n_profiles.py`
- German documentation: `docs/de/`
- English documentation: `docs/en/`
- German README: `README.md`
- English README: `README.en.md`

Translation keys are dot-separated and grouped by surface, for example `nav.models`, `signals.connected`, or `state.saved`.

## Product Components

The model packages are prepared as multilingual product components. German remains the domain default, and English is the fallback and second language. The directly integrated additional product locales are:

`es`, `fr`, `pt-BR`, `it`, `nl`, `pl`, `tr`, `ja`, and `zh-Hans`.

Every chat model contains:

- `meta.defaultLocale`: `de`
- `meta.fallbackLocale`: `en`
- `meta.supportedLocales`: complete product locale list
- `meta.productI18n`: localized name, description, suggestion, and profile path
- `i18n/<locale>.md`: product-specific Knowledge profile for that language
- `i18n/manifest.json`: package manifest for local product profiles

The API importer uploads `i18n/` together with `mainprompt.md`, `fachwissen.md`, the model-defined example result file such as `beispielergebnis.md`, `beispielergebnis.html`, or `beispielergebnis.json`, and `beispiele/` into the Knowledge collection of each model. The dashboard uses `meta.productI18n` for localized model names and descriptions; if a locale is missing, it falls back to English and then German.

## GitHub

GitHub shows `README.md` as the repository landing page and does not automatically translate this view by visitor language. Multilingual Markdown files therefore need visible language links. German remains the default file; English variants use `.en.md`.

## Unicode and UTF-8

All relevant text files remain UTF-8. Umlauts, accents, emojis, non-Latin characters, and bidirectional text can be preserved in visible prose. Technical tokens are not transliterated or translated when they are part of paths, IDs, API fields, commands, or file formats.

## Adding a Language

1. Add `Workbench/dashboard/static/locales/<lang>.json` with the same keys as `de.json`.
2. Extend `SUPPORTED_LOCALES` in `Workbench/dashboard/i18n.py` and `SUPPORTED_LOCALES` in `Workbench/dashboard/static/app.js`.
3. Extend product locales in `SUPPORTED_PRODUCT_LOCALES` in `scripts/generate_model_i18n_profiles.py` and `scripts/configure_openwebui_tool_models.py`.
4. Run `python scripts/generate_model_i18n_profiles.py`.
5. Add `docs/<lang>/index.md` and more translated documentation pages where useful.
6. Add language links in README files and central documentation pages.
7. Add tests for locale detection, fallbacks, product profiles, and Unicode.
8. Run `python scripts/verify_openwebui_workspace.py`.

## Local Testing

```powershell
$env:WORKBENCH_LOCALE="en"
python scripts/generate_model_i18n_profiles.py
python -m unittest discover Workbench.dashboard.tests
python -m Workbench.dashboard.server --host 127.0.0.1 --port 8088
```

The browser UI can also be switched with the language selector in the dashboard top bar.
