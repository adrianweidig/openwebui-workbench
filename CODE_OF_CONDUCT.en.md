# Code of Conduct

🌐 Languages: [Deutsch](CODE_OF_CONDUCT.md) | [English](CODE_OF_CONDUCT.en.md)

This project should be a respectful, factual, and productive place for technical collaboration.

## Expected Behavior

- communicate respectfully and concretely
- keep technical criticism focused on code, documentation, tests, or traceable decisions
- account for different experience levels
- respect security and privacy boundaries
- resolve conflicts early and factually

## Unacceptable Behavior

- personal attacks, insults, or demeaning language
- harassment, discrimination, or intimidation
- publishing private data or credentials
- intentionally disrupting issues, pull requests, or reviews
- pressuring others to disclose security details publicly

## Enforcement

Maintainers may moderate, close, hide, or reject contributions when they violate these rules or put the project at risk. Security issues are also covered by `SECURITY.en.md`.
