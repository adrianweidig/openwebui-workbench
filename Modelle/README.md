# Modelle

Dieser Ordner enthaelt die operativ relevanten Modellartefakte.

## Unterstruktur

- `einzelmodelle/`: menschenlesbar sortierte Modellpakete mit `model.json`, `systemprompt.md`, `mainprompt.md`, `fachwissen.md` und `README.md`
- `dist/`: Air-Gap-Handover fuer Copy/Paste, ZIP und Fallback-Import

## Nutzung

- Fuer inhaltliche Pruefung und manuelle Bearbeitung `einzelmodelle/` verwenden.
- Fuer Transport in die Zielumgebung oder gebuendelte Uebergabe `dist/` verwenden.
