# Beispiele für Paket 1

Dieses Verzeichnis enthält vollständige Offline-Referenzen für die Migration.

## Reihenfolge

1. `eggplant/*.script` lesen.
2. `migration-inventory.csv` als Klassifizierungsmuster prüfen.
3. `migration-output/*.md` als Antwortmuster nutzen.
4. `generated-csharp/` als Zielcode-Referenz verwenden.
5. `test-assets/` für VisualTrack-Tests verwenden.
6. `pipeline/azure-pipelines.visual-track-snippet.yml` für Azure DevOps Server übernehmen/anpassen.
