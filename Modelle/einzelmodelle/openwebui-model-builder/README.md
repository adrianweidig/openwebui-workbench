# OpenWebUI Model Builder

OpenWebUI-Modellumsetzung des Custom GPT `OpenWebUI Model Builder` aus `adrianweidig/custom-gpts`.

## Zweck

Erstellt vollständige OpenWebUI-Modellpakete mit `model.json`, `systemprompt.md`, `mainprompt.md`, `fachwissen.md` und optionaler README/Icon-Vorbereitung.

## Referenz

Quelle: `https://github.com/adrianweidig/custom-gpts/tree/main/OpenWebUI%20Model%20Builder`

## Import

`model.json` ist ein OpenWebUI-kompatibles JSON-Array mit genau einem Modellobjekt. `mainprompt.md` und `fachwissen.md` werden beim API-Import als Knowledge für dieses Modell hinterlegt.
