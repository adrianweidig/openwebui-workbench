# Icon Prompt für das OpenWebUI-Modell „Testprogrammierung“

Erzeuge ein klares, modernes App-Icon für ein KI-Aufgabenmodell namens „Testprogrammierung“.

Motiv:
- stilisierte Codeklammern oder ein Test-Häkchen
- dezente CI/CD-Pipeline-Linie
- kleine Symbole für Playwright/Selenium-artige Browserautomation ohne Markenlogos
- technischer, professioneller Eindruck
- Fokus auf Testautomatisierung, Codequalität und zuverlässige Builds

Stil:
- minimalistisch
- flaches Vektor-Design
- gut lesbar als kleines OpenWebUI-Modell-Icon
- dunkler oder neutraler Hintergrund
- kontrastreich
- keine realen Firmenlogos
- kein Text im Bild

Format:
- quadratisch
- zentriertes Symbol
- geeignet für Web-App-Navigation und Modellkachel
